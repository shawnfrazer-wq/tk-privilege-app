# TK Privilege

The client loyalty app for Tatiana Karelina salons. Start with CLAUDE.md, then docs/crm-api.md.

React Native with Expo and Expo Router. Screens are in app/, shared pieces in src/, the design in wireframes/all-screens.html.

    npm install
    npx expo start
    npx eas-cli build --platform ios --profile production

Stage 1 (opening, sign in, code, Home, Card, How points work, Your Points, Visits, Contact, FAQs) is built. Rewards, Your Details, booking, Refer a Friend and Review follow in the next stages.
